# Landing-page artwork

The landing page uses three original, text-free images generated for this project and optimized to WebP:

- `public/images/duelke-hero.webp` — 1920×1080, 107 KB
- `public/images/duelke-chess.webp` — 1200×800, 87 KB
- `public/images/duelke-checkers.webp` — 1200×800, 89 KB

No third-party image is embedded in the page. Unsplash search results and the source/License pages were reviewed only as visual references; their images were not copied into the project. The license/source pages reviewed were [Unsplash license](https://unsplash.com/license) and [one chess-photo source page](https://unsplash.com/photos/black-chess-piece-on-chess-board-nEbMedmVwgw). The source-page text extraction did not expose a creator attribution, so that image was not used.

The hero uses a decorative empty alt because the chess artwork is atmospheric and the headline supplies the message. Game-preview images have descriptive alt text. Below-the-fold previews lazy-load, reserve intrinsic dimensions, and use local WebP assets so page rendering does not depend on a remote image host.
